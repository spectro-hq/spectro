# @spectro/core

Browser-independent Spectro event pipeline: event construction, privacy filtering, bounded queues and transport contracts. Most web applications should install `@spectro/browser` instead.

This alpha package is released together with `@spectro/browser`, `@spectro/types`, and `@spectro/protocol`. Import from the package root. Do not rely on private file paths.
