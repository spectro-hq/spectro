# @spectro/types

Spectro SDK configuration, capture, queue, delivery and transport contracts. Includes the runtime delivery constants consumed by core and browser packages.

This alpha package is released together with `@spectro/browser`, `@spectro/core`, and `@spectro/protocol`. Import from the package root. Most web applications only need `@spectro/browser`.
