# Hosted browser acceptance

Mode: Operate. Extend the existing local-only Browser acceptance harness; do not redesign the Console or change SDK APIs. The owner approved testing real scoped write-key ingestion, four browser signal categories, and Console/session evidence. Existing identities, organizations, projects, and keys remain untouched.

## Direction contract

THESIS: Connect the owner's saved Browser Key to real local ingestion and make acceptance or rejection visible without exposing credentials.

OWN-WORLD: Inherit Spectro's system sans, restrained ultraviolet primary action, neutral surfaces, readable labels, and monospaced machine status. No imagery, decorative motion, or new brand system.

STORY: Confirm project/environment, paste the key locally, connect, send explicitly labeled test signals, then open the live Console. The key is memory-only and cleared from the input after connecting.

FIRST VIEWPORT: One compact connection form above the existing signal controls and read-only status. Controls stay disabled until connected. At 390px fields and actions stack without horizontal overflow.

FORM: Narrow extension of the existing harness; no concept seed or comp round applies. Native controls and explicit inline failure recovery remain the working grammar.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Its compact native form and stacked narrow-screen controls remain local to this acceptance surface; no new global component or visual-world rule was introduced.
