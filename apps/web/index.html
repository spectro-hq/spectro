Integrate the Spectro browser SDK into this app.

Install @spectro/browser@0.1.0-alpha.0, call init() once at
startup with our projectId, environment, browser write key,
ingestion origin (no /v1/envelope — the SDK appends it) and
release, then instrument the key product actions with
track(). Follow the SDK guide for the API:
https://github.com/spectro-hq/spectro/blob/main/packages/browser/README.md

Paste it into Claude Code, Cursor, Codex or any agent that can edit your repo. It performs the same steps below with your real project settings.

or integrate by hand

  1. Install

    npm install @spectro/browser@0.1.0-alpha.0

  2. Initialize and track

    import { init, track } from '@spectro/browser';

init({
  projectId: 'YOUR_PROJECT_ID',
  environment: 'production',
  apiKey: 'YOUR_BROWSER_WRITE_KEY',
  endpoint: 'https://YOUR_INGESTION_ORIGIN',
  release: 'YOUR_APP_RELEASE',
});

track('checkout_started', {
  source: 'cart',
});

    The SDK is in alpha. Replace the example values with your project settings. Use the ingestion origin without /v1/envelope; the SDK appends that path. Restrict your browser write key to your app’s allowed origins.

privacy

Capture with care

By default, the browser SDK excludes passwords, input values, cookies, authorization headers, request and response bodies, and element text. It does not capture DOM snapshots or screen recordings.

Interaction capture observes only explicitly marked elements. Review custom event properties before sending them; filtering is not a substitute for deciding what your app should collect.

Not collected by default

  • passwords
  • input values
  • cookies
  • authorization headers
  • request and response bodies
  • element text
  • DOM snapshots
  • screen recordings
faq

Before you begin

What can I investigate today?

Browser errors, performance, network activity and sessions, plus custom events. Release views and the shared event explorer connect these signals to captured evidence.

Does Spectro record the screen?

No. Spectro captures structured events and their context. Session timelines show those events; they do not record screens or take DOM snapshots.

Is the browser SDK open source?

Yes. The browser, core, types and protocol packages are MIT-licensed. They are currently in alpha. The hosted platform’s license is separate and has not been finalized.

How does early access work?

Submit a public request on GitHub with your frontend stack and what you want to investigate. Do not include credentials, private project details or customer data. The team can follow up in that issue; a request is not a confirmed invitation.
