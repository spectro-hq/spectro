## Generated-comp factual errata

These are genuine content defects in the generated proposals, not permission to recompose an approved layout. Reconcile them with source schemas during implementation:

- Session and Page are payload contracts, not common contracts (example-led and reference-split images group them incorrectly).
- `source.url` is a bounded string in the schema, with no JSON Schema URL format restriction. Browser URL sanitization is a separate capture policy.
- `source.line` and `source.column` are integers with minimum 0, not minimum 1 (reference-tabs image).
- The protocol does not specify stack-frame order; omit the generated chronological claim.
- A schema identifier is not a network download link. References resolve locally; copying the identifier does not fetch it.
- Requiredness for array items is not object-property requiredness. Display item structure without an invented Optional marker.
